# Key layout (top to bottom, left to right)

```
[ C ] [ ⌫ ] [ ÷ ] [ × ]
[ 7 ] [ 8 ] [ 9 ] [ − ]
[ 4 ] [ 5 ] [ 6 ] [ + ]
[ 1 ] [ 2 ] [ 3 ] [ = ]
[     0    ] [ . ] [ = ]   (= spans two rows)
```

Keyboard: digits and `.`; `+ - * /`; `Enter` or `=`; `Escape` = C; `Backspace` = ⌫.

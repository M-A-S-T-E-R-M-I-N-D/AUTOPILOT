A static site with nothing to build

This sample has no package.json, no bundler, and no server-side code — just hand-written HTML and CSS. It exists so AUTOPILOT's static-site onboarding detector (packages/onboarding/src/gate/detectors/static-site.ts) has a real fixture to flight-test against, the same way sibling samples exercise the js and python detectors.

Read more on the about page — every link on this site stays local so the gate's link check never depends on network access.

Part of AUTOPILOT's samples/ target-repo fixtures.

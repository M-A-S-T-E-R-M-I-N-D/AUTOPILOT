What this sample proves

Most target repos AUTOPILOT flies have a manifest — a package.json, a pyproject.toml — that names a gate directly. A static site has neither, so the static-site detector recognizes the ecosystem from the files themselves: no manifest, at least one .html file.

The gate

Two checks, both run through npx --yes since there is no local install to reuse:

  • html-validate **/*.html — lints every page for markup errors.
  • linkinator . --recurse — crawls every page from the home page and fails on a broken link.

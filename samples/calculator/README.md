# Calculator sample

A classic pocket calculator, born as a red-tests-first mission and flown to green by AUTOPILOT
autonomously. `MISSION.md` is the seed brief (its checklist reflects seed time); the honest
flight story — including what went wrong — is
[`docs/CASE-STUDIES/calculator.md`](../../docs/CASE-STUDIES/calculator.md).

- Run the tests: `npm test` (12/12 green)
- Use it: open `index.html` in any browser — mouse and keyboard both work
- Sequential evaluation like a real pocket calculator: `2 + 3 x 4 = 20`, by design
